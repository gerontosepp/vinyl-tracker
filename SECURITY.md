# Security Policy

## Supported Versions

Only the latest released version of Vinyl Tracker receives active security updates and patches.

| Version | Supported          |
| :---    | :---               |
| 2.4.x   | :white_check_mark: |
| < 2.4.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Vinyl Tracker, please do **not** open a public issue.

Instead, please report the vulnerability responsibly via GitHub Private Vulnerability Reporting:
1. Navigate to the **Security** tab of this repository.
2. Click **Report a vulnerability** to privately submit details to the maintainers.

### What to Include in Your Report
- Detailed description of the issue and potential impact.
- Step-by-step instructions or proof-of-concept (PoC) to reproduce the vulnerability.
- Affected components (Backend, Frontend, MCP Server, Docker deployment).

### Our Commitment
- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will work to investigate and address confirmed vulnerabilities promptly.
- Once fixed, a security advisory and patched release will be published.
